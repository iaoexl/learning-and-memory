# 个人成长与方法库（learning-and-memory）

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/deed.zh)

> 一个以「学习科学 + 竞技记忆」为骨架的个人成长知识库。把学习方法、笔记体系与记忆训练重构成**可查、可练、可验证**的体系：每一篇都从板块0 出发，按板块递进，落到操作流程、自检清单与案例复盘。
> 
> 本仓库是个人成长与学习科学知识的整理、汇编与重构，属学习研究资料。每篇笔记自足、格式统一，打开即用。
